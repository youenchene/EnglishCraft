# La progression repose sur des preuves déterministes

Les niveaux de maîtrise sont attribués par le moteur pédagogique à partir de tentatives observables, jamais sur la seule affirmation d’un LLM. Cette contrainte limite la flexibilité des évaluations ouvertes mais garantit une progression traçable, reproductible et testable ; les futures évaluations IA fourniront seulement une preuve structurée que le domaine pourra accepter ou refuser.
